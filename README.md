# 4 держателя телефона для перелётов — Mercado Livre Brasil (Rio de Janeiro, CEP 22640-102)

Одностраничная HTML-подборка: держатели телефона для самолёта с Mercado Livre Brasil.

- №1 — универсальный складной механический держатель (вариант цвета Preto);
- №2 — ESR Travel / Airplane Magnetic Phone Holder (MagSafe);
- №3 — Ulanzi SK-20 Suporte Celular Tripé Portátil Para Viagem (Preto), R$ 45, рейтинг 5,0, «MAIS VENDIDO» — алюминиевый складной держатель + мини-штатив (данные со скриншотов карточки от 28.08.2026);
- №4 — Suporte Dobrável Rotativo Celular Do Avião (Preto), R$ 27,25, продавец YOUNENGHU (MercadoLíder), рейтинг 4,9 — данные со скриншотов карточки от 28.08.2026.

## Ссылки

Кнопки «Открыть на Mercado Livre» ведут прямо на карточки товара (share-ссылки из приложения Mercado Livre). Содержимое карточек Mercado Livre скриптом не проверялось (сайт блокирует автозапросы) — цену, продавца, рейтинг и доставку до CEP 22640-102 нужно сверять в самой карточке. Для №2 и №3 добавлены референсные ссылки на сайты производителей ESR и ULANZI.

## Фото

- №1 — типовое изображение складного механического держателя этого класса (публичная карточка Mercado Livre не даёт отдельного фото);
- №2–3 — с сайтов производителей ESR и ULANZI (папка `img/`).

## Прочее

- Анимации — Framer Motion (`motion`) через ESM CDN; контент виден всегда, при недоступности JS/CDN страница остаётся полностью читаемой (прозрачность не анимируется).
- Проверено: 28.08.2026. Цены и наличие могут меняться.
