# 5 держателей телефона для перелётов — Mercado Livre Brasil (Rio de Janeiro, CEP 22640-102)

Одностраничная HTML-подборка: 5 держателей телефона для самолёта с Mercado Livre Brasil.

- Механический зажим или MagSafe, в основном до R$100, один премиум-вариант (R$100–150).
- Все ссылки кликабельны и ведут на поиск Mercado Livre по названию товара — нужно выбрать активное предложение указанного продавца.
- Фото каждого держателя видно на странице:
  - №1–2 — типовые изображения складных механических держателей этого класса (публичная карточка Mercado Livre не даёт отдельного фото);
  - №3–5 — с сайтов производителей LISEN, ESR и ULANZI (папка `img/`).
- Анимации — Framer Motion (`motion`) через ESM CDN; при отключённом JS весь контент виден.

Проверено: 28.08.2026. Цены и наличие могут меняться; точный срок и стоимость доставки до CEP 22640-102 Mercado Livre показывает после ввода адреса.
